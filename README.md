# Site Laços Solidários

## Apresentação
Projeto acadêmico de desenvolvimento front-end para uma ONG fictícia, com páginas institucionais, apresentação de projetos e formulário de cadastro.

## Tecnologias utilizadas
- HTML5 para estrutura e conteúdo.
- CSS3 para layout, responsividade e identidade visual.
- JavaScript para navegação, interações, validações e comportamento dinâmico.
- Git e GitHub para versionamento, branches, commits, issues e pull requests.

## Estrutura do projeto
- `index.html`: página inicial.
- `projetos.html`: apresentação dos projetos.
- `cadastro.html`: formulário de cadastro.
- `css/`: arquivos de estilo.
- `js/`: scripts da aplicação.
- `imagens/`: recursos visuais.

## Execução local
1. Clone o repositório.
2. Abra a pasta do projeto no WebStorm ou outro editor.
3. Abra o arquivo `index.html` no navegador.
4. Não há dependências externas obrigatórias nem processo de build.

## Versionamento
O projeto utiliza GitFlow simplificado:
- `main`: versão estável.
- `develop`: integração do desenvolvimento.
- `feature/`: novas funcionalidades.

As mensagens de commit seguem o padrão Conventional Commits, com tipos como `feat`, `fix`, `style`, `docs` e `chore`.

## Funcionalidades
- Navegação entre as páginas do projeto.
- Layout responsivo.
- Cards de projetos e campanhas.
- Formulário de cadastro com validações e feedback ao usuário.
- Estrutura preparada para comportamento de SPA.
